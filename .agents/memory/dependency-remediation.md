---
name: Dependency remediation constraints
description: Compatibility and audit-fix pitfalls when addressing workspace vulnerabilities
---

Keep security remediation on the existing Expo native SDK line when patches and narrow compatibility adaptations can resolve the findings.

**Why:** A wholesale Expo/React Native migration would require a different native runtime and broaden a dependency-security task into a product migration.

**How to apply:** Check both file-based image bundling and byte-based image sizing after image parser upgrades; typechecks alone cannot detect a changed runtime input contract.

Do not assume overlapping overrides generated by `pnpm audit --fix` compose to select the newest patched version.

**Why:** Multiple advisory ranges for the same package selected older fixes in this workspace even after a successful automatic fix and install.

**How to apply:** Consolidate overrides into compatible major lines, regenerate the lockfile, and audit the actual resolution rather than trusting the auto-fix exit code.
